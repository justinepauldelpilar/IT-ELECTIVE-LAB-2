# Justine Del Pilar — React Portfolio

A responsive multi-page portfolio built with React, Vite, React Router, and Tailwind CSS.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open a terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Routes

- `/` — Home
- `/about` — About
- `/projects` — Projects
- `/contact` — Contact
- Any unknown route — 404 page

## Deploy to Vercel

1. Push this project to the existing GitHub repository.
2. Import `justinepauldelpilar/IT-ELECTIVE-LAB-2` in Vercel.
3. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
4. Deploy. The included `vercel.json` supports direct route refreshes.
